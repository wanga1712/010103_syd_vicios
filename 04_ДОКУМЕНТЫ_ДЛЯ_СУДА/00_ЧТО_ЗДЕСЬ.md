# Документы для суда

Здесь находятся шесть финальных текстов:

1. Письменная позиция ответчика.
2. Ходатайство о приобщении доказательств.
3. Ходатайство об истребовании доказательств.
4. Ходатайство о страховщиках.
5. Ходатайство о вызове лиц.
6. Резервное ходатайство об экспертизе.

Файлы являются ссылками на канонические документы в `review_md` внутри Git-репозитория. Изменения в канонических файлах автоматически отражаются здесь.

`00_Статус_пакета.txt` показывает готовность текста и PDF.

В папке `Word` находятся редактируемые версии всех шести документов.

PDF не собраны.
