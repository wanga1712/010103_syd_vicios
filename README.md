# 010103_syd_vicios

Обезличенный рабочий репозиторий для подготовки защиты по делу.

Оригиналы, персональные данные, фото, PDF и служебные экспорты не публикуются.

## Состав

- `docs/DEFENSE_STRATEGY_V2_REDACTED.md` — стратегия защиты;
- `docs/ACTION_LOG_REDACTED.md` — журнал действий;
- `docs/EVIDENCE_MATRIX_REDACTED.csv` — матрица повреждений;
- `docs/REQUESTS_STATUS_REDACTED.md` — статусы запросов;
- `docs/OPEN_QUESTIONS.md` — открытые вопросы;
- `schemas/evidence.schema.json` — схема строки матрицы;
- `tools/` — служебные описания, без встроенных персональных данных.

## Псевдонимы

- `CLAIMANT` — истец;
- `DEFENDANT` — ответчик;
- `VEHICLE_A` — повреждённое ТС;
- `VEHICLE_B` — второе ТС;
- `INSURER` — страховая организация;
- `COURT` — суд.
